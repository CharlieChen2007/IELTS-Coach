# AI 接入验收与交付边界

本次在「布局与切换完善版」基础上接入统一的 DeepSeek 服务端适配。原有听说读写、校园营地、个人资料、词汇工作区及已确认的导航、插画与切换动效保留。交付方式为项目 ZIP，由 WorkBuddy 发布公网服务。

## 接入内容

- `modules/ai/deepseek.mjs`：服务器统一配置模型与密钥，支持文本和 Task 1 图片；JSON 校验、响应大小上限、超时、取消和不泄露密钥的异常响应。
- `scripts/writing-api.mjs`：写作精修沿用原生 Task 1/Task 2 合同与逐句批注流程，报告模型来源如实返回，失败释放请求额度。已交卷原稿保持不可变。
- `modules/speaking/server/`：口语追问、文本反馈与报告改用 DeepSeek；修通公开站点的会话身份。语音证据只能来自本人、已封卷题号和成功的整段腾讯评测，不能用客户端传来的分数替代。
- `modules/study-coach/` 与 `src/StudyCoach.tsx`：听力、阅读真实交卷报告可生成证据约束的深入复盘，列出可能错因和下一步练法。模型不能改分、改标准答案、增加积分或指定外部跳转。
- `docs/WorkBuddy部署说明.md`、`deploy.env.example`：服务器配置、持久化要求、公网验收步骤及可复制的交接提示词。

## 已完成的测试方法

模型测试仅替换外部供应商响应，账号、同源检查、SQLite 数据库、接口路由、额度和缓存均使用真实实现。没有真实付费 API 调用，也未读取或打包用户的真实密钥。

共享适配与写作覆盖真实 Task 1 题图完整传递、模型配置、Node/Worker 环境隔离、JSON 与截断返回、空内容、大小限制、超时、取消、失败退额度和最后一次额度的并发竞争。听读覆盖不可变答卷取证、本人归属、引用原句、模型字段限制、缓存、并发去重、失败退款与数据库重启。口语覆盖会话身份、原始转写、腾讯回执归属、题号与分段绑定、模型输出引文及缺证据不猜发音分。

原有回归已验证听力四段 22 题与专项、阅读 18 篇 217 题、写作同编号提交冲突、校园互助/诊所及双账号约练。浏览器验收与最终构建结果在交付时追加于本文件。

- `npm run build`：通过 TypeScript 与生产构建；生成的口语 Worker 通过语法检查。
- `npm run verify:ai`：通过共享/写作 74 项检查、口语服务端链路和听读深度复盘测试；供应商响应均为替身，没有付费调用。
- 听读复盘浏览器测试：使用真实 AuthProvider、SQLite 和替身模型，覆盖 StrictMode、成功/失败/未配置、生成中切换报告及账号，390/320px 无横向溢出。
- 口语自动队列浏览器测试：未封卷等待期间没有重复解码/上传；封卷后自动完成三题评测；真实刷新后恢复已保存答卷的等待任务；报告仅提交会话标识，不上传音频给 DeepSeek。替身腾讯回执的 50/100、75/100 指标与文本反馈分开展示，无伪造总分，无页面 JS 错误。
- 既有 120 项契约检查，以及听力、阅读、写作不可变提交、校园诊所、搭子约练、营地成长、每日语料与词汇账号隔离测试通过。
- 实际 ZIP 解压目录回归：48 个页面路由、20 个窄屏路由、37 次内嵌文档检查通过。使用实际占宽滚动条，未发现第二条整页滚动轴、横向溢出、裁切或页面 JS 错误。
- 实际 ZIP 在没有 `node_modules` 的新目录中可导入服务、自动建表、建立站内会话、交阅读答卷并查询 AI 状态，Node 服务器能直接启动。压缩包完整性和解压文件哈希校验通过。

## 必须如实展示的限制

1. 压缩包不含密钥；配置存在只表示具备发起请求的条件。真实模型可用性、费用和实际音频评测，必须由 WorkBuddy 配好 Secret 后按部署说明逐项验收。
2. DeepSeek 分析文本与图片，不接收原始录音。发音与语流指标来自腾讯及对实际评测 PCM 的测量；环境噪声可能影响声学指标。
3. 腾讯百分制不等于雅思分制。发音显示真实百分制；没有校准依据，不编造线性换算或四维雅思总分。文本维度仅作练习参考。
4. 现有昵称/浏览器会话账号可供多人访问同一公网服务，但没有因此自动实现跨设备邮箱身份找回。数据库与录音对象需要平台持久化磁盘和备份。
5. 浏览器语音识别、系统朗读和麦克风能力存在设备差异。真实手机与真实模型验收仍须在线上环境完成。
