# 接回验收与交付说明

基线为 IELTS-Coach-WorkBuddy交回版.zip。修复包使用独立目录，首次启动自动建库与迁移。

## 功能覆盖

| 区域 | 本轮检查与修复 |
| --- | --- |
| 首页与外壳 | 登录、演示切换、四科入口、个人空间、手机菜单、重复点击保留表单、刷新及返回 |
| 听力 | 四段原声与 22 题、十三种专项题型、服务端判分、逐句定位回听、错因与复练、历史同步 |
| 口语 | 全流程及快速模考、自由对话、双人模拟、备考小组、录音与自动评测队列、语音诊所、历史 |
| 每日语料与词汇 | 三个跟读视图、录音防重入、离页保护、原声刷新回放、词汇翻卡与保存、两账号隔离 |
| 阅读 | 八个视图、18 篇 / 217 题权威判分、原文依据、单词/错题/学习档案、切页保存、不可变历史与全站联动 |
| 写作 | 六个视图、199 张图表题图及 Task 2 题库、两类提交、逐句锚点、建议采纳、二稿对比、不可变快照、历史与复练 |
| 校园 | 搭子画像/招募/邀请/约练/练后交流、互助认领/一次回复/复练解决、四人挑战、养成/经验/排行/积分/校级目标 |
| 个人记录 | 历史筛选与报告、不同题量听读按正确率比较、分数与正确数单位、错题返回原题、个人和校园资料 |
| 公共保存 | 按账号与来源窗口校验、主站串行代发、待同步副本、失败回执与重试、防并发覆盖 |

## 本次继续优化

- 阅读首页新增大型书本、写作首页新增稿纸钢笔插画，沿用听说模块的蓝色渐变、描边与阴影。下方题库、统计及作答顺序保留。
- 口语整理为口语训练、同伴练习、跟读训练、学伴互助、口语记录五类。诊所和互助单只在学伴互助的第二级切换；双人模考与备考小组分为两个子页。
- 阅读与写作均收为三个一级分类，细项由二级工具承接。点击当前一级不重置二级、作答或草稿；旧深链与浏览器前进后退继续可用。
- 通用词汇迁到独立 `#/vocabulary`，沿用现有账号、保存接口与学习记录；阅读语境生词工具保留。首页四科卡与日常积累分组显示。
- 修复写作无报告时被强制弹回概览：保留所选复盘子页，显示准确空态和开始写作按钮。
- 修复四科互助卡片误跳口语或仅回大厅：现在直接打开对应示例或真实单详情。已有真实单不再显示无人发单提示，示例仅在演示空间出现。
- 本机昵称登录与独立演示空间分别判断。搭子、邀请角标、互助案例和排行不再因本机登录而混入模拟数据；演示开关切换时更换对应工作区，原账号数据保留。
- 二级切换移到一级分类工具栏右侧，窄屏自然换行。口语、阅读、写作及校园分类统一控件外观，使用共享滑动高亮；布局变化直接校准，减少动效偏好关闭位移。
- 修复听力分数环的垂直对齐及主站报告环的水平对齐，分子与分母仍共基线；检查头像、题号、排行徽标及跟读分数环。
- 修复入场缩放期间误测 iframe 高度的问题，统一按未变换的布局尺寸上报。普通原文展开后跟随主文档滚动，弹窗、错题抽屉及受限选项列表保留必要滚动。
- 词汇 800 词长列表改为每页 24 词，筛选覆盖全词库并重置页码；记忆状态比例按真实词库总数计算。修复写作实际 Radix 题库仍使用固定定位而被裁切，以及窄屏概览统计的横向溢出。

## 已修复的主要回归

阅读和写作的本地键已按账号隔离。私人学习接口使用校园会话 cookie 识别参与者。交卷后切科目仍由主站完成提交，历史报告保留当时题目与原稿。写作相同编号并发提交不同内容会返回冲突，已提交原稿保持不可变。

互助单恢复正确详情路由，诊所链接参数已修复。回复后显示回执并收起输入框。双人模考与备考小组恢复独立页签。新搭子约练使用新版阅读篇章及写作题目，后端检查本人完成对应提交后再允许分享心得。

每日跟读和词汇保存已移交主站队列。录音支持离页保护、防重复评分，原声按账号保存在原浏览器的 IndexedDB，刷新后可以回听。

去除了反复强制读取布局以重启动画的代码，以及开场持续逐帧性能探测。保留约 1.12 秒的品牌开场并与正文进场接力；应用加载更慢时等待应用就绪。嵌入模块使用统一字体、动效和外壳规则，手机保留一套主站底栏。公共脚本已拆为应用、React 和云 SDK 缓存块。

听读页面显示正确率及实际正确数。写作基础规则反馈明确显示其来源。综合练习估分仅在本人两篇完整真实 AI 报告齐备时汇总。Task 2 的权重依据 IELTS 官方说明，按 Task 1 : Task 2 = 1 : 2 计算练习参考值。[IELTS Academic Writing](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing)

## 验收证据

全新目录依赖安装与 TypeScript / Vite 构建通过。接口检查覆盖听力判分、阅读 217 题、双账号、并发去重、修改冲突、积分幂等、重启恢复、诊所和校园互助。浏览器走查覆盖所有一级和二级功能页，以及核心提交、切页和刷新流程。动效与手机布局脚本检查实际位移、错落时序、异步模块及减少动效偏好。新导航专项覆盖草稿、旧深链、返回、隐藏 iframe 消息隔离；独立词汇专项覆盖实际记忆操作、立即切科目、刷新及双账号隔离。

本次继续优化的专项记录：48 条路由走查；58 项动效与布局检查；32 项词汇迁移实际操作；127 项交互与响应式检查。读写主视觉在 1440、768、390、320px 共八组截图检查。测试覆盖真实/示例互助详情、同页切演示后返回、演示搭子接受与约练、普通账号的真实发单。脚本使用各自测试账号及临时数据库，未将测试数据库打入交付包。

本轮布局复验：236 项分类切换与布局检查，涵盖 1440、1280、1024、768、390、320px 六个宽度、实际滑动中间值、最终落点、校园导航文档身份、二级右对齐和减少动效偏好；73 项居中验收，采样 322 个标识，并检查 125%/150% 缩放。单滚动轴专项明确关闭浏览器默认隐藏滚动条，探针测到 15px 实际占宽，检查 2048、390、320px 下各内嵌视图的动画中及停止后尺寸、听力四段提交与结果、原文、词表分页、词条弹窗、写作题库与三次跨尺寸切换。极窄屏另修听力结果工具条、跟读提示和阅读错题行的收缩与换行，保持答案、状态和展开按钮可达。

本轮听说录音流程采用浏览器虚拟麦克风与测试音频。该方法验证采集、保存、提交、回听及去重，不提供真人发音评分校准结论。

## 外部配置及交付边界

- 本包可直接用于课程演示。默认昵称加邮箱是本机账号流程，公开生产的云账号需配置平台域名、账号服务与授权。
- 写作真实 AI 精修尚未通过实际付费模型调用验收。当前无密钥时提供逐句基础规则反馈；Task 1 的真实评估需要支持图像的模型。报告会准确标注来源。
- 腾讯 SOE 可沿用本机 Windows 加密凭据，其他电脑需配置服务端环境变量。评测分是练习反馈。
- 跟读原声保存在原浏览器，跟读学习记录同步到服务器。跨电脑回听原声需要后续增加原声上传。
- 已检查 Chromium / Edge 桌面及窄视口。iOS Safari 的真实设备录音与移动网络条件尚未验证。
- WorkBuddy 提供的写作原生界面只有编译后的资源。本包保留这些资源，并提供可读的接入、规则反馈、快照及综合分模块。长期深度修改原生写作界面时应补齐该模块原始工程。
- ZIP 包含运行所需的构建产物、代码、素材与数据库迁移。个人数据库、凭据与私人录音由运行机器保存。
