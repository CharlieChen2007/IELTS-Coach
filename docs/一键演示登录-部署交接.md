## WorkBuddy 原样部署

1. 将本包解压到新的独立发布目录；不要混入旧 dist 或覆盖原数据目录。
2. 使用 Node.js 24，执行 `node scripts/release-integrity.mjs verify`，必须为 verified=true。
3. 保留原服务器的 DeepSeek、腾讯 SOE、域名等运行环境变量，以及原来的 IELTS_DATA_DIR 数据目录和其中数据库。不得把密钥写进源码或前端。
4. 原样启动 `HOST=0.0.0.0 PORT=平台端口 node scripts/start.mjs`，本包已有 dist，不需要 npm ci、重新构建或修改代码。
5. 验证 `/api/release` 的 releaseId/codeDigest 与包内清单一致；打开 `/#/auth?mode=signup`，点击「演示模式一键登录」，确认首页显示 Test、处于演示状态、历史记录非空，个人资料邮箱为 test@qq.com。
6. 退出再进入及刷新各验一次；提交公网链接与 `/api/release` 校验结果。
