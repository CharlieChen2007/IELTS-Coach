# 2026-11-11 四科修复与写作算法接入

基线为本次提供的「AI 全启用版」，不是回退到之前的旧版。原个人作业冻结包、旧交付包和本次原始附件均保留。本版需要 Node.js 24；完整前后端一起部署，不能只上传静态网页或使用旧 Worker 入口。

## 验证码：代码修复与平台待办

旧工程把验证码 SDK 指向先前的 WorkBuddy 域名。用户提供的线上探测记录表明旧配置和当前站点认证通道均不可用。HTTP 状态本身不足以证明应用被删除，但可以确认不能把当前通道当作已可正常发送。

本版去掉失效的固定绑定，默认使用当前站点源地址；服务器通过 `/cloud-config.js` 下发以下**公开配置**，无需修改或重建前端：

| 服务器变量 | 内容 |
| --- | --- |
| `WORKBUDDY_PUBLISHABLE_KEY` | 当前激活应用的 `publicConfig.publishableKey`，必须为 `wbpk_` 公开标识。 |
| `WORKBUDDY_CLOUD_ENDPOINT` | 可选，填激活返回的 endpoint；不填则使用当前域名。不要自行猜测新地址。 |
| `WORKBUDDY_OAUTH_RELAY_BASE_URL` | 可选，填激活返回的 oauthRelayBaseUrl。 |

部署人员必须先激活当前应用、挂载认证路由并启用短信/邮箱渠道，再配置公开值。没有完成这一步，本包**不声称真实验证码收发已恢复**。未配置时页面明确提示，不伪造验证码或登录状态。

代码已补充请求超时、重发冷却、更换收件人、重复点击保护、切换渠道/模式时忽略旧响应，以及缺少有效用户身份不能假登录。发送成功只表示供应商接受发送请求，不等于已经投递到手机/邮箱。真实收码应由本人在网页自行输入完成验证，不要把验证码发到聊天。

## 阅读

桌面做题与就地解析恢复原文、题目双栏独立滚动；工具栏与交卷可见。题号仅定位右栏，证据仅定位左栏，不再带动整个主页面。首页、题库与工具页继续自然高度。窄屏保留原文/做题切换并检查 320/390px。引文改用更清晰的浅蓝整句标记，辅助文字提高字号与对比度。已提交答卷可进入现有主站学习报告，不额外自动调用 AI。

## 写作

使用本次三个交接算法：Task 1 v1.0、Task 2 v1.1、写作评分 v1.1。评分移至本人会话鉴权的服务端，题干与题图取自本项目题库，不接受浏览器伪造题图、分数或评分依据。报告保存为不可变记录，同文重试命中缓存。

Task 1 保留核心分数、引文和图表事实校验；辅助字段出现可保守处理的冲突时降级对应内容，不把有效的整份批改直接丢弃，也不编造缺失的图表事实或范文。真正的证据错误仍拒绝并退还本次批改额度，页面保留原稿及可定位的错误编号。

社区画像保留原评分算法的最近一组 Task 1:Task 2=1:2 结果；另明确命名 `all-first-drafts-v1`，汇总全部合格首稿：两类各自求均值，再按 1:2 合成，舍入到 0.5。排除修订稿、重复同文和示例。只有一种任务时显示样本未齐，不捏造完整写作总分。校园卡片仅公开参考值和两类样本数，不公开作文、报告内容或记录编号。该参考值没有声称经雅思考官校准。

写作首页主按钮改为真正进入编辑器；换题菜单、进入编辑器后的外层滚动、空二稿对比、范文与逐句批注文案一并复核。

## 听力与口语

听力保留独立交卷与确认重做：取消重做会保留答案，确认“清空并重做”才清空，这项调查观察不是判题缺陷。结果卡与小屏布局继续复核。

口语修复云端场次摘要无法恢复主站完成数的问题。顶部改为真实腾讯百分制的最近发音，不把无四维总分误显示为雅思估分。设备试录增加时长和实时输入电平，自选话题、朗读按钮和等待状态更清楚。

浏览器支持原生语音识别时默认开启转写并允许关闭；不新增付费 ASR，不把原始录音传给 DeepSeek。没有转写仍可录音、交卷和腾讯评测；手工补字不冒充完整原始转写。调查使用的静音/假音频被有效声音检查拒绝时，不取消检查来制造评分。

## 部署和验收

保留当前线上 DeepSeek、腾讯服务器 Secret 和持久化数据卷，替换源码不要清空数据库。生产构建：`npm ci` → `npm run build` → `npm start`。新表自动创建，已有提交继续保留。

本轮模型与验证码自动化测试使用替身供应商，SQLite、身份、路由、额度、缓存与浏览器交互使用真实代码，没有发送真实短信/邮件或消耗付费模型。最终测试结果在交付前追加。
