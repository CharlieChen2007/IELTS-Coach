# 写作精修室「功能不变 · 展示方式统一」报告

> 用户反馈：*「我反复跟你强调需要风格统一。当前写作你是直接接进去的，但是我实际上需要的是你保持功能不变的前提下将前端设计全部统一成像是听和说的板块一样，相当于功能不变，统一展示方式」*。

本轮把上一版「整页 iframe 直接塞入独立站皮肤」改成 **IELTS Coach 四科同一套展示语言**，同时保证交接包的功能逻辑、题库、批改链路、草稿与数据库**一行不改**。

站点仍遵守长期交付规则：**部署上线 + 集成数据库 + 可直接访问链接**。

---

## 一、问题定位：差异到底在哪

先对照三张截图做了 DOM / computed style 实测，结论是**色板本来同源，差异在「展示方式」而不是配色**：

| 维度 | 听力 / 口语（基准） | 上一版写作（问题） |
| --- | --- | --- |
| 科目横幅 | 主站钴蓝 `.subject-hero` | 已有，一致 |
| 导航 | **横向功能页签**（4 / 7 个） | iframe 内**竖排侧栏**「你的写作历程」，主站只有 2 个页签 |
| 主视觉 | 浅蓝渐变 hero + 白卡 + 蓝色按钮 | **黄色玻璃纸飞机大图** + 34px 文艺大字 + 英文大写 kicker |
| 卡片 | 白底 / 18px 圆角 / 浅蓝描边 / 双层柔影 | 独立站紧凑卡片、柠檬黄强调 |
| 文案 | 中文功能标题 | `A LITTLE BETTER, EVERY DRAFT`、`YOUR PRACTICE DESK` 等 |
| 外壳 | 无独立站痕迹 | 品牌 logo、面包屑、账号头像、页脚 |

写作包自身的 `:root` 是 `--blue:#4388c4 / --canvas:#f5f8fb / --radius:18px`，与主站 `--brand:#4388c4 / --page:#f5f8fb / --radius:18px` 本就一致（两者同源于同一份 handoff 色板）。所以**不需要改色板，要改的是布局壳与视觉语言**。

## 二、落地方式：只统一展示层，功能零改动

### 1. 导航上移：竖排侧栏 → 主站横向页签

`src/pages/WritingPanel.tsx` 重写为 6 个横向页签，与听力「训练首页 / 分段训练 / 题型训练 / 学伴互助」、口语「模考室 / 自由对话 / 每日语料 / 词汇 / 学伴互助 / 口语诊所 / 口语记录」同款 `.speaking-tabs`：

```
练习概览 | 写作精修 | 批改报告 | 二稿对比 | 练习记录 | 学伴互助
```

前 5 项一一对应交接包原有的 5 个 `.nav-item`。关键约束：

- **iframe 常驻不重建**：页签互切只发一次 `postMessage({type:'navigate', view})`，
  `public/writing/assets/writing-host.js` 把它翻译成对原有 `.nav-item[aria-label=…]` 的一次 `.click()`，
  触发交接包自己的 `setView`。编辑器草稿、滚动位置、正在播放的内容都不丢。
  验收用 `window.__writingProbe` 标记确认切页签后 iframe 仍是同一个 frame。
- **双向同步**：交接包内部自己跳转（hero「开始今天的写作」、报告里「进入二稿」）时，
  用 `MutationObserver` 监听 `.nav-item.active` 回报主站，主站 `replace()` 同步地址栏与页签高亮。
- **空态保护不破坏**：无提交时交接包的 `goReport` / `goCompare` 只弹提示、不切视图，
  这是原有业务逻辑。桥接层在点击后强制回报「实际停留的视图」，主站页签自动回落到真实位置，
  **不会出现页签高亮与内容错位**（这处是实测发现后补的）。

### 2. 独立站外壳隐藏，但功能不删

`scripts/writing-entry.mjs` 生成薄入口，首帧前内联样式隐藏 `.sidebar / .topbar / .footer / .mobile-nav / .brand / .loading-screen`，并把 `.main-shell` 的 `margin-left` 归零。

导航 DOM **仍在文档里**，只是不可见；桥接层正是靠它驱动视图。导出 / 恢复备份在「练习记录」视图里有完整落点，隐藏侧栏不丢功能（已实测 `导出记录`、`恢复备份` 按钮均存在）。

### 3. 一层主题样式统一视觉语言

新增 `public/writing/assets/writing-theme.css`，**仅在 `html.host-embedded` 生效**，独立访问 `/writing/index.html` 时交接包保持原样。对齐 `src/styles.css` 的 design tokens：

| 项目 | 统一后 |
| --- | --- |
| hero | `--grad-hero` 浅蓝渐变 `linear-gradient(120deg,#edf7ff,#dcf2fc)` + 右上柔光圆（同 `.hero-card::after`），移除黄色纸飞机插画 |
| 标题 | 34px / 字距 1px 文艺大字 → 24px / 字距 -.6px 主站功能标题 |
| 卡片 | 所有视图的 `.panel / .overview-panel / .score-card / .diagnosis-card / …` → 白底、18px 圆角、`#e3ebf2` 描边、主站双层柔影 |
| 按钮 | `--grad-primary` 蓝色渐变、8px 圆角、13px、40px 最小高度 |
| 标签 | 英文大写 kicker → 中文功能标签；`soft-label` 改品牌浅蓝底 |
| 强调色 | 柠檬黄装饰 → 品牌浅蓝渐变 |
| 字体 | 与主站同一字体栈；英文作文正文保持 Georgia（同 `.essay-box`） |

### 4. 文案调性统一（纯展示，不动逻辑）

`components/writing-studio.tsx` 中把独立站的文艺文案与英文装饰标签换成中文功能向：

- `A LITTLE BETTER, EVERY DRAFT` → `写作精修 · 分项练习`
- `YOUR PRACTICE DESK` → `练习概览`；`YOUR WRITING STUDIO` → `写作精修`；
  `TASK 2 · ARGUMENTATIVE WRITING` → `TASK 2 · 议论文`；`EVERY DRAFT COUNTS` → `练习记录`
- `FIRST DRAFT / A BETTER DRAFT / LEARN FROM THE REVISION` → `首稿 / 修订稿 / 参考范文`
- hero 标题 `每一次改写，都离目标更近一点。` → `分项精练，逐句打磨每一稿。`
  描述改为功能说明；三个视图的文艺页标题 → `批改报告 / 二稿对比 / 练习记录`
- 顺带修掉一个原有脏数据展示：综合分空态会拼出 `还差一份 undefined 首稿`，
  补上 `gaps.length === 0` 兜底为 `综合练习估分待生成`。
- 概览区在 iframe 1132px 宽度下会命中交接包 1190px 窄断点导致标题居中，
  主题层拉回左对齐，与四科的「左对齐区块标题 + 白卡」一致。

## 四、保持不变的部分

- **功能**：Task 1 199 张题图、Task 2 260 道题库、富文本编辑器、四维估分、逐句反馈、
  二稿对比、练习记录、草稿自动保存、游客模式、导出 / 导入备份，全部原样运行。
- **数据库**：`/api/writing/workspace` GET / PUT 按站内账号隔离（SQLite），
  localStorage 仍是游客模式的真实存储，云端仅作跨设备备份。
- **AI 通道**：`/api/ai/chat`、`/api/writing/ai/status`、未配置时结构化降级与内置估分引擎不变。
- **动画口径**：页签行静止，只有 `.stage-body` 一层 `hero-in`，实测 `running=1`。
- **首帧静默**：iframe 就绪前透明，无骨架、无「正在…」、无独立站顶栏闪帧。
