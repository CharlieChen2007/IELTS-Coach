# 写作接入与修复

使用本次提供的 Task 1 v1.0、Task 2 v1.1、Writing Scoring v1.1。算法源码、Schema、提示词、题库索引与离线测试保存在 `modules/writing-engine/`，UPSTREAM.md 保留原资源交接说明；本整合工程的使用方式以此文及整站 README 为准。

## 批改链路

前端原生编辑器通过既有 `evaluate` 接口调用 `POST /api/writing/evaluate`。服务端验证当前校园会话、固定原稿、从本站可信题库加载题干/题图，并调用原生算法，成功后锁定完整报告及摘要哈希。模型结果不再由浏览器独自验收。请求只含 task、questionId、submissionId、text、mode，客户端传入分数、事实表、首稿身份或任意提示词均拒绝。

同一账号、题目和正文重试复用已锁定结果，不挑更高分；并发同稿请求合并。已固定的提交编号不能被另一份正文覆盖。首稿/复批由服务端历史确定，二稿历史和首稿原文保留；旧版工作区同步仍可用，但客户端上传的旧报告不进入新的可信匹配基线。

Task 1 的 v1 契约严格限制完整估分、图表引用、自动改数字、修订预算等。新增宿主 `task1-host-delivery-v1` 仅保守处理辅助交付：supported 的影响统一为 none，来源不清时降级并去掉不可支持的分数，无法核实的数字与超预算改写保留原句并给出手动核对方向，ready 与未核实事实矛盾时改为需复练，范文不合格时明确不可用。不会补造原文引用、提高分数、假装图表已核实。错误引句、错误题号、错误核心评分等仍拒绝并可重试。

Task 2 保留资源 v1.1 的短稿修复、manual 编辑限制和独立范文状态。范文不可用不再把有效评分整份丢弃；已达到收尾条件而保留原文时，界面明确标为“原稿参考版本”，不冒充升级改写。Task 1 编辑器与算法使用同一字数正则，数字和百分比不再导致不同读数。

新入口每份成功批改计一次本站额度；缓存重看不扣，验证/调用失败归还。一次批改可能包含读图/审题及有限格式重试，本站次数不是供应商实际请求数或 Token 费用。失败保留原稿并提供错误码和追踪编号；不向用户暴露密钥或供应商原始报错。

## 所有首稿与社区匹配

`GET /api/writing/profile` 仅向当前本人返回画像，导出 `readWritingProfile(env,owner)` 供服务端校园匹配使用。

- `result`、`matchingSource`：原算法3，最近一组符合条件的 Task 1 与 Task 2 首稿快照，保留其来源、90天样本时效及7天配对规则。
- `hostAggregate`：另行标记 `all-first-drafts-v1`，纳入全部合格首稿，各类先按有效稿求未舍入均值，再按 Task 1 : Task 2 = 1 : 2 汇总，最后展示到0.5。缺一个任务时总分为 null。返回两类样本数、证据ID和排除原因，不择最高分，不纳入二稿、示例、语言片段、来源不完整或不兼容的旧报告。

社区只应公开最小的综合参考、完整性及两类样本数，不公开正文、引文或私有报告。这里的“首稿”是服务器记录的该题第一提交，不能证明用户从未见题、未在站外得到帮助或已经考官校准；画像用于学习配对参考。

## 界面修复

概览主按钮进入当前任务编辑器；换题面板可见，离开页面时收起；导航滚到编辑区顶部时避开主站顶栏，自动保存和高度更新不抢滚动。没有二稿时不再显示“0个段落有变化”。重复的保留句解释收起，辅助标签字号/颜色改善。保留三组主导航与原有二级工具，不另建一套界面。

## 验证

`node scripts/verify-writing-engine.mjs` 使用真实 SQLite、真实身份与算法，仅将供应商替换为离线响应。覆盖两任务成功、辅助反馈降级、严格证据拒绝、失败退额、同稿缓存、异账号、全部首稿均值及二稿排除。

`node scripts/verify-writing-browser.cjs` 使用独立临时构建和真实浏览器，覆盖概览按钮、可见题库、Task 1 完整批改、Task 2 原生投影、二稿空态、字数一致和390px布局；可用 CHROMIUM_PATH 指定 Chromium/Edge。

原算法测试：`node --test modules/writing-engine/task1/tests/task1.test.mjs modules/writing-engine/task2/tests/task2.test.mjs modules/writing-engine/task2/tests/task2-delivery.test.mjs modules/writing-engine/scoring/tests/scoring.test.mjs`，82项通过。

本轮未使用真实 Key 或付费请求。上线仍需配置服务器凭据，并使用真实图表和作文做实际供应商验收。运行要求 Node 24；本次写作算法包含 Node 文件/加密接口，按完整 Node 服务部署。
