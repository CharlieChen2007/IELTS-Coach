# 全站进场动画审查与收敛报告

> 2026-11-09 · 动画收敛版
> 验收脚本：`scripts/check-motion.mjs`（32 项，全部通过）

## 一、本轮变更缘起

上一版把动画「覆盖到所有每次加载出来的页面」，逐元素错落 + 页签逐个浮起，
一次点击十几个动画同时跑。用户反馈：

> 动画的量加过头了……其实每次点击训练首页-分段训练那一行的时候只有下面的这些
> 是需要有动画的，别的是不需要的，不然就会闪的眼睛花，其他地方也同理。

红框指向**页签下方的主内容区**：顶部蓝色科目横幅、页签行、侧栏、顶栏一律要静止。
因此本轮把口径从「越多越好」彻底反转为「**一次点击只有一层动画，只在主内容区**」。

## 二、收敛后的动画架构

| 层 | 元素 | 行为 |
|---|---|---|
| 外壳 | 侧栏、顶栏、科目横幅 `.subject-hero`、页签行 `.subject-tools` / `.speaking-tabs`、校园活动行 | **完全静止**，不挂任何动画 |
| 主内容层 | `.stage-body`（页签下方的正文 / iframe 舞台 / 卡片） | **唯一**常驻 `hero-in .62s` 的一层；换页面时随 `.page-view` 重建自动播一次 |
| 页内切换层 | `.stage-pane`（报告 / 资料 / 每日语料二级页内切换） | 默认静止，仅 `.replay-enter` 时原地重播一次，不与外层叠加 |

关键实现：

- `.page-view` 的 `key` 只算路由名 / 科目名，**不含 query、也不含 `enter` 序号**。
  点页签时外壳 DOM 原地不动，iframe 不重建（不丢录音 / 滚动位置）。
- `enter` 序号只用于普通页面（首页 / 历史 / 曲线 / 错题 / 资料 / 报告）的 `.stage-body` 重建。
- `useEnterReplay(trigger)` 改为**原地重置动画**（remove class → 回流 → add class），
  不再重建 DOM / iframe；动画结束自动摘掉 `.replay-enter`。
- 首页 hero 内部逐元素淡入全部关闭，整块主内容由 `.stage-body` 统一进场，避免两层叠加。

相较上一版删除的做法：`.page-view > *` 无差别挂动画、卡片内部逐元素错落、页签逐个浮起、
`.replay-scope` 多块各自错落、以及靠 `!important` 去「禁止」外壳动画——现在外壳根本不挂动画。

## 三、验收口径（32 项，全部通过）

`check-motion.mjs` 全量重写，判定标准从「运行中的动画数量」改为「**恰好一层 + 外壳静止**」：

| 分组 | 口径 |
|---|---|
| A1 左侧导航逐个点入 | 恰好 1 个 `hero-in` 在跑，外壳元素 `animationName === 'none'` |
| A2 深链 + 刷新 | 同上 |
| A3 浏览器后退 | 同上 |
| B 页内切换 | 外壳不重建、只有一层重播、iframe 不重建 |
| C 关闭动效 | `prefers-reduced-motion` / `?motion=off` 下零动画、内容全部可见 |
| D 本轮专项 | 首页词汇入口、词汇 iframe、`/api/daily/vocab` GET/PUT、口语 iframe 首帧导航隐藏、可见「正在…」文案静默、无 JS 异常 |

采样用 `getAnimations({ subtree:true })` + `getComputedStyle().animationName` + `playState === 'running'`，
真实点击侧栏 / 个人空间入口，覆盖深链、刷新、后退、减少动效档位。

## 六、关闭动效

| 触发方式 | 动画 | 内容 |
|---|---|---|
| `prefers-reduced-motion: reduce` | 归零 | 全部可见 |
| `?motion=off` | 归零 | 全部可见 |

两条分支已对 `.stage-body` 与 `.stage-pane.replay-enter` 补齐 `animation:none !important`，
关闭后不再有 `hero-in` 在播，也没有元素停在半透明状态。
