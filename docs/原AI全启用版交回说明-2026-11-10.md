## 使用前须知：本包不含密钥

为避免泄露，打包时已排除 `.env` 与 `deploy.env`。解压后需要自己建一份 `.env`：

```
HOST=0.0.0.0
PUBLIC_ORIGIN=http://localhost:8787

DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash

TENCENT_APP_ID=
TENCENT_SECRET_ID=
TENCENT_SECRET_KEY=
```

不填也能跑：所有做题、判分、题库、进度、校园功能都不依赖密钥；AI 讲解与发音评分会自动降级，界面如实提示，不伪造分数。

## 启动

需要 Node.js 24.0+（要用内置 `node:sqlite`）。

```
npm ci
npm run build
node scripts/start.mjs
```

Windows 可直接双击「启动整合版.cmd」。首次启动会在 `.data/` 下自动建库并跑迁移。

本包已包含 `dist/` 成品，也可以跳过 build 直接启动。

## 与上一版的差异

1. `modules/speaking/dist/practice.js`：修「口语 · 自由对话」在嵌入态整页空白——`alive()` 把 IndexedDB 存储名 `host:<scope>` 与服务端身份 `guest_<hash>` 直接比较，恒不相等导致不渲染。
2. `modules/speaking/server/tencent-soe.mjs`：修 Node 环境下 SOE 评测 100% 失败——原代码用 `fetch(url,{headers:{Upgrade:'websocket'}})` 取 `response.webSocket`，这是 Cloudflare Workers 的用法，Node 的 undici 不支持。现按运行环境分支：Node 用原生 `WebSocket`。
3. `modules/speaking/dist/server/index.js` 已按上述修复重新打包。

## 上线前必须处理

- `.data/` 是实例本地盘，容器重建即丢。长期使用请把 `IELTS_DATA_DIR` 指向持久卷。
- 不要把这个包连同 `.env` 一起分发。
