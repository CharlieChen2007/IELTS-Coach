# 听力与口语调查复核

基于本次用户提供的 AI 全启用版和两份 2026-11-10 调查报告处理。调查文件记录的是观察，未把每条读数都当作产品故障；下列区分真实修复、已验证行为与外部服务边界。

## 口语

| 调查位置 | 处理结果 |
| --- | --- |
| O-01/O-02/O-03：已交卷但总站完成数仍为 0 | 修复云端场次摘要只有 `turnCount`、没有 `turns` 时被发布器拒绝的问题。启动从本人服务端场次摘要恢复总站记录；已有报告、分数和原始作答不被摘要覆盖。 |
| O-01/O-02：最近模考估分长期为空 | 横幅改为“最近发音”，只读取本人已完成的真实腾讯评测百分制。排除演示/示例记录，不把百分制换成雅思分。没有有效结果时显示“待评测”。 |
| O-04：设备检测只有录音文案、没有经过时间 | 增加实际试录计时，结束后显示录制时长。输入电平条根据实际采集电平改变高度与颜色；不播放随机假波形，减少动效偏好关闭过渡。 |
| O-05：“跳过朗读”显示禁用 | 朗读控制显式按是否正在录音/待保存作答更新状态。播放中可跳过；跳过后“开始回答”恢复可用，录音中仍不播放题目污染录音。 |
| O-08/O-09/O-10：0 次 SOE、无转写 | 报告使用假设备、关闭转写且 Part 2 只说约 2 秒，不能据此证明真实评分失效。保留有效声音检查、完整模考与原始转写门槛，不给静音或短演示伪造分数。另修默认可用性：支持浏览器识别时默认按偏好开启，用户可关闭；不支持时明确说明并禁用无效开关。 |
| O-09：失败段统一显示“评测未完成” | 汇总区分评测中、待封卷同步和需要查看原因的段数；全部失败明确“未取得有效评分”，不继续伪装为正在等待。原录音仍可回听。 |
| O-11：两级分类与 iframe 隐藏导航数量不同 | 两级分类是统一宿主入口；iframe 内旧导航隐藏，数量不必一一对应。保留现有分类，不恢复重复入口。 |
| O-12：自选话题未输入时点“开始聊”没有反馈 | 空白或没有英语内容时禁用开始按钮，旁边解释可选择话题卡或填写英语话题；输入有效话题后立即启用。 |
| O-12：跟读为本地节奏评估、人机模拟不计分 | 保留准确的来源与演示标识，不把本地节奏指标当作腾讯发音分或正式模考分。 |
| O-13/O-14：手机布局与小字 | 验证 390/320px 评分状态布局；口语辅助文字提高可读性。手机侧栏须先点击菜单打开，隐藏侧栏文本在测试中点不到并不等同于菜单失效。全站共享文字样式由主整合统一处理。 |

浏览器转写还补充了故障保护：连续三轮无结果后停止重启，错误不无限轮询，不影响独立麦克风录音；识别服务自然结束后可重启，已完成文本保留，final/interim 替换不重复附加；停止识别最多等待 650ms，异常不能阻塞交卷。

## 听力

| 调查位置 | 处理结果 |
| --- | --- |
| O-01：统计和标签对比度 | 保留统一统计布局，听力工作区次要文本加深；主站共享标签由主整合统一处理。 |
| O-02/O-03/O-04：练习入口、试听与停止 | 流程成立。停止播放/切换音源导致浏览器取消媒体请求属于正常取消，不把 `ERR_ABORTED` 当作业务错误。 |
| O-05/O-06：嵌入练习台与播放器 | 保留当前功能接入。四段浏览器真实交卷及 390/320px 结果布局通过；iframe 实现本身不影响功能，不因调查结构文字不同重写整个模块。 |
| O-07/O-08：交卷与漏答确认 | 四段独立服务端判分成立；未答满会先确认，确认前不提交。22 题正确答案、错题归档和其他段状态保持。 |
| O-09：答案片段比标注起点稍早 | 属于播放器预留前后文，帮助听清更正信息。增加“含少量前后文”标注，避免把片段定位理解为播放精度错误。 |
| O-10/O-11：首页进度和错题本 | 保留分段统计与独立错题本；后台测试覆盖隔离、复练幂等和重启持久化。 |
| O-12/O-13：13 类题型与单题训练 | 保留完整目录、四类分段与九类原创专项。标准答案、部分得分和重做由程序判定，不让 AI 改写正确率。 |
| O-14：未加入校园时的互助入口 | 校园资料是发布的共同入口，调查未实际提交不等同于发布失败；不去掉参与权限和录音隐私控制。 |
| O-15：深入复盘与生成后缓存 | 保留已提交答卷取证、引用校验和缓存，不为展示重复消耗模型额度。 |
| “重做本段”后仍看到原答案 | 调查只打开确认，没有点“清空并重做本段”。实测取消重做保留原答案；确认重做后七个输入框清空、结果收起，刷新仍为空；其他段和历史交卷保留。 |
| O-16：移动端 | 四段结果在 390/320px 均无横向溢出；尺寸改变后等待布局稳定再取读数。 |

## 可复验命令

安装依赖后使用 Node >=22.13。浏览器项用 `CHROMIUM_PATH` 指定已安装的 Chromium/Edge。

```sh
node modules/listening/verify.mjs
node scripts/verify-speaking-transcription.mjs
node scripts/verify-speaking-browser.cjs
node scripts/verify-listen-speak-controls.cjs
```

上述检查使用真实 SQLite、本站身份和接口、实际浏览器录制/播放控件；录音输入为 Chromium 假设备，不是人工真实麦克风录音。模型与腾讯上游用替身响应或明确关闭，不消费付费服务。真实手机、浏览器厂商语音识别服务、真实腾讯音频质量与真实 DeepSeek 响应仍应在部署后验收；不以配置存在代替调用成功。
