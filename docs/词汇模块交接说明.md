## 1. 这个模块是什么，边界在哪

学术类雅思 AI 陪练网站中的**词汇模块**，定位是「每日词汇」：用户每天用卡牌过一批词，系统按遗忘规律安排复习，并用听写检验拼写。

**负责**：卡牌翻面与自评、间隔重复调度、今日队列与打卡、记忆曲线与到期预测、听写判分、词表检索、本模块内的账号隔离。

**不负责**：全站登录与用户体系、路由框架、后端与数据库、音素级发音评分、官方词表授权、跨设备同步。

> 本项目为 Demo：账号体系（`speakloop.users.v1`）与所有数据都在浏览器本地，属于**占位实现**，第 5 天应由前端负责人统一替换。

## 4. 功能与验收

### 4.1 卡牌

- 正面：单词、英式音标、词性、发音按钮。
- 反面：中文释义、英文释义、例句（词高亮）、例句译文、搭配 / 同义 / 词根提示（**缺失字段自动隐藏**，不留空行）。
- 翻面：点击卡牌或按 `空格`，3D 翻转 620ms。
- 评分：`1` 忘了 / `2` 有点难 / `3` 记住了 / `4` 太简单，每个按钮标注下次复习时间。
- `D` 键朗读单词；`E` 无效（例句需点按钮）。

### 4.2 今日进度与打卡

- 今日目标默认 15 词，可按账号改（`settings.target`）。
- 进度 = 今日新学 + 今日复习；侧栏队列已完成的打勾。
- 达到目标当次写入连续打卡；跨天断档重置为 1。

### 4.3 记忆曲线

- 四个指标：今日待复习、学习中 / 复习中、已掌握（间隔 ≥21 天且 reps ≥3）、今日听写正确率。
- 未来 7 天到期柱状图（第 1 天含所有逾期）。
- 单卡复习历史折线：纵轴为间隔天数（<8 天保留一位小数），单次记录补虚线；下方给出复习次数、当前间隔与估算保持率。

### 4.4 听写

- 只播发音、不显示拼写；可重复播放（听写页按空格也可重播）。
- 判分先归一化（小写、去空格与连字符）再算 Levenshtein：距离 0 正确；短词 ≤1 / 长词 ≤2 提示「差一点」但不计正确。
- 答错按 `again` 写入该词（次日复习）；答对不替代主动回忆评分。
- 一组 10 题，结束给正确率、评语与错词清单。

### 4.5 词表

- 800 词网格、关键词搜索（英文 / 中文 / 英文释义）、主题与掌握状态筛选。
- 点词条打开详情，可直接「现在复习这个词」插入当前队列。

### 4.6 验收清单

- [ ] 打开页面 → 卡牌正面只有单词 / 音标 / 词性，释义被遮挡
- [ ] 空格翻面 → 出现释义、例句、搭配与四档评分
- [ ] 点「记住了」→ 进度 +1，队列打勾，卡片写入 `localStorage`
- [ ] 连续 15 个 → 今日达标、连续打卡 +1
- [ ] 听写一组 10 题 → 正确 / 差一点 / 错误三种反馈，结束有正确率与错词
- [ ] 记忆曲线 → 四个指标、7 根柱子、单卡折线
- [ ] 词表 → 800 个词、搜索「sustain」有结果、主题筛选正常
- [ ] 刷新 → 进度与打卡仍在；新建账号 → 记录归零

## 5. 数据契约

### 5.1 编号

| 对象 | 规则 |
|---|---|
| 词条 | `W_001` – `W_800`（自动分配，跳过已占用编号） |
| 卡片 | 以 `wordId` 为键，不另建 id |
| 听写 | `D_VOCAB_*`（一次 10 题） |
| 学习会话 | `S_VOCAB_*` |

### 5.2 数据结构

```text
word    { id, word, phonetic, pos, zh, def, ex, exZh, colloc?, syn?, tip?, level, topic }
        ex 中的 ~ 是词本身占位符，渲染时替换
card    { wordId, reps, ease, interval, due, lapses, last,
          history[{ date, q, interval, ease }] }
每日     { "YYYY-MM-DD": { learned:[wordId], reviewed:[wordId], dictation:{total,correct} } }
统计     { total, fresh, learning, reviewing, mastered, due,
           learnedToday, reviewedToday, dictationTotal, dictationCorrect, accuracy }
```

`level`：2 = 目标 6.5–7.0，3 = 7.5+。`syn` / `tip` 仅核心 88 词具备，其余词条省略。

### 5.3 存储

```text
speakloop.users.v1         用户列表（占位）
speakloop.lastUser.v1      当前用户
speakloop.vocab.<userId>   本模块数据：cards / daily / streak / settings
```

### 5.4 契约位置

- 源码：`assets/vocab-data.js` 末尾的 `CONTRACT`，挂载为 `SL.contract.vocabModule`
- 导出：`node tools/export-vocab-contract.js` → `contracts.vocab.json`
- 控制台：`SL.contract.vocabModule`、`SL.vocabData.WORDS.length`

## 6. 调度算法（SRS）

```text
again(0)  重置：interval=1, reps=0, lapses+1, ease-0.2，次日重来
hard(1)   不重置：interval = reps>0 ? round(interval*1.2) : 1，ease-0.15
good(2)   reps 0→1 天；reps 1→4 天；之后 round(interval*ease)
easy(3)   reps 0→3 天；reps 1→7 天；之后 round(interval*ease)，ease+0.15
边界      interval 上限 180 天；ease 夹在 1.3–3.0
```

**为什么 `hard` 不重置**：若把「想起来了但很吃力」当作遗忘，用户会永远停在 1 天间隔，且 `lapses` 虚高。只有 `again` 才是真遗忘。

掌握度：`fresh`（无记录）/ `learning`（interval <7）/ `reviewing`（7–20）/ `mastered`（≥21 且 reps ≥3）。

记忆保持率：`exp(-距上次复习天数 / (interval × 2.2))`，**仅用于可视化，不是分数**。

## 7. 并入整站的步骤

1. **复制文件**：`vocab.html`、`assets/vocab-*.js`、`assets/vocab.css`、`assets/styles.css`、`assets/audio.js`、`assets/module-contract.js`。
2. **恢复导航**：在 `vocab.html` 的 `#nav` 里加回 `<a class="nav-btn link" href="index.html">← 返回主站</a>`。
3. **脚本顺序**：保持 §3 的顺序，`vocab-data.js` 后必须紧跟 `vocab-bank.js`。
4. **账号**：页面启动时取 `userId`；把 `speakloop.users.v1` / `lastUser.v1` 换成统一登录态即可。
5. **存储替换**：`vocab-app.js` 里只有四处需要改 —— `keyOf()`、`loadDb()`、`saveDb()`、`grade()` 的落库调用；听写在 `submitDict()` 里写 `recordDictation`。
6. **样式**：词库依赖 `styles.css` 的 CSS 变量与 `.btn` / `.card` / `.pill` / `.input` / `.modal` / `.toast`；换肤优先改变量。
7. **联调自检**：`node tools/vocab-count.js && node tests/vocab.test.js && node tests/vocab.e2e.test.js`。

> 同一 DOM 树里不要同时挂载主站与词库页：两者都用 `#view` / `#toast` / `#modal` / `#accountBtn`，会 id 冲突。

## 9. 已知限制与待办

| # | 限制 | 影响 | 建议 |
|---|---|---|---|
| 1 | 800 词为**精选高频词**，非官方完整词表 | 覆盖率有限，不能宣称「雅思全部词汇」 | 按 `vocab-bank.js` 的格式继续追加，自检脚本会自动查重 |
| 2 | `syn` / `tip` 只覆盖核心 88 词 | 部分卡牌没有同义替换与词根提示 | 可批量补齐，UI 已支持缺失隐藏 |
| 3 | 发音依赖系统 TTS 语音包 | 无语音包时听写无法听题 | 部署时补预录音频，或提示用户 |
| 4 | 数据只在 localStorage | 换设备 / 清缓存即丢失 | 接后端，字段见 §5.2 |
| 5 | 未上云部署 | 只有本地地址 | 走云环境激活与发布流程 |
| 6 | 词表一次渲染 800 张卡 | 低配设备首屏略慢（实测可接受） | 需要时加虚拟滚动或分页 |
| 7 | e2e 硬编码 Chrome 路径 | 换机器需改常量 | 改为读取环境变量 |
| 8 | 音标为人工整理 | 个别词可能有偏差 | 上线前用权威词典校一遍 |
