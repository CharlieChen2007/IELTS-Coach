# 阅读双栏与调查复核

本轮依据阅读调查记录及用户截图，修复被全站滚动统一误伤的阅读工作区。调查包中的正常观察不作为缺陷修改；原题库 18 篇、217 题、规则判分、错题本、阅读生词与精读工具保留。

## 修复结果

- **原文与题目分开滚动**：只有做题及交卷后的就地解析进入固定高度双栏；两栏滚轮互不影响。首页、题库列表和学习工具仍由主站自然滚动。
- **工具栏保持可见**：计时、已答题数、精读、交卷和返回题库不随题目消失。进入练习时将工作区放到主站顶栏下；改变视口时重算可用高度，手机底部导航不遮住最后的内容。
- **定位各归其位**：点题号只滚题目栏，点解析中的原文证据只滚原文栏，不把另一栏或主站页面一起拉走。窄屏保留“阅读原文 / 做题”，从证据返回题目仍可回到原题。
- **解析更易辨认**：原文依据采用整句浅蓝底及下沿；悬停与点击均可见。原样引用、正确数和标准答案不变。
- **对话框与词卡**：未答题交卷确认框显示在当前工作区内；阅读词卡夹在实际可见区域，滚动所在栏后收起，避免悬在旧位置。
- **统计口径与可读性**：同一篇反复练习记“次”，不误称不同“篇”。辅助标签改用更清楚的字号与颜色，题号居中，移动切换保留明确选中态。
- **学习报告可直达**：交卷工具栏连接本人已保存的 `rpt_rd_*` 学习报告，可继续查看现有 AI 深度复盘；打开报告本身不额外调用模型，不修改规则成绩。

## 桌面与手机验证

`node scripts/check-reading-workspace.cjs` 使用真实阅读前端、真实 SQLite 和同源服务端接口，无模型调用，覆盖：

- 桌面两栏独立滚轮、固定工具栏、题号定位、证据定位及明显高亮。
- 未答题交卷取消、实际提交 12/13、原稿与标准答案锁定。
- 1024、990、390、320px；移动原文/题目切换、无横向溢出及无整页 iframe 滚动条。
- 词卡边界、栏内滚动关闭词卡、返回题库及恢复普通页面高度。

另以隔离 Vite 构建在真实主站 `ReadingPanel` 验证了顶部位置、双栏滚动、390px、一级分类返回与交卷后的本人学习报告入口。无页面 JavaScript 错误。`node modules/reading/verify.mjs` 再次通过 18 篇 217 题、不可变服务端判分、并发去重、账号隔离、校园积分及重启持久化回归。

浏览器脚本需要 `npm ci` 后通过 `CHROMIUM_PATH` 指定 Chromium/Edge（本机已有兼容 Chromium 时也可直接运行）。

## 维护约定

嵌入态练习根节点使用 `data-reading-workspace="split"`。高度由主站可用视口确定，不使用 iframe 的 `100vh` 推算自身高度。不要再用全局 `overflow:visible` 覆盖该工作区的 `.pane`，也不要让 `scrollIntoView` 在双栏内无条件代理到父页。普通页面仍沿用原来的自动高度协议。
