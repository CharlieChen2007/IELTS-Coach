## 三、界面一体化：全页只有一条滚动轴

这是本轮用户明确指出的重点。原来写作题库弹窗有内部独立滚动条，右侧还有主站外层滚动条，滚轮在不同区域控制不同容器。

| 位置 | 改动 |
| --- | --- |
| 阅读 `.mode-practice` / `.pane` | `height:100vh` + `overflow-y:auto` → 自然高度、`overflow:visible` |
| 阅读 `.dlg-overlay` / `.rd-overlay` | fixed 遮罩 → 页内白卡（`position: static`） |
| 写作 `.question-bank-content` / `.dialog` / `.topic-picker-*` | 同样改为自然高度页内白卡；fixed `.toast` 由主站统一提示接管 |
| 滚动代理 | `window.scrollY` / `scrollTo` / `scrollIntoView` 转发到主站 `document`；弹窗出现时 `reveal` 自动带到卡片位置 |
| 高度同步 | 量「内容真实底部」而非 `documentElement.scrollHeight`，规避兜底高度死锁；主站最小高度与模块下限统一为 320 |
| 进度备份 | 切到「学伴互助」时 iframe **只隐藏、不卸载**，避免文档销毁打断正在发出的备份请求 |

实测（写作「浏览题库」）：弹窗 `position: static`、`overflow-y: visible`、内容高度 1140 = 可视高度 1140、iframe 内可滚动容器 **0 个**；主站 `scrollHeight 1980 > clientHeight 900`，滚轮只控制主站这一条轴，卡片随整页一起滚动。

顺带修复了「切到学伴互助 → iframe 卸载 → 最后一次进度备份 `net::ERR_ABORTED`」这一真实隐患：现在两个 Panel 都保留 iframe，切回来仍是同一个文档，草稿、阅读位置与高度原样保留（验收里专门加了 4 项切回验证）。顶栏也统一改为不透明实色，滚动时不再有内容透出。

## 四、数据库与服务端接口

| 接口 | 说明 |
| --- | --- |
| `GET /api/reading/status` | 返回 `configured:true` / `table:reading_state` / `scopeIsolation:true` |
| `GET /api/reading/state` | 读取当前账号的 `yl.v1.*` 全量备份 |
| `PUT /api/reading/state` | 防抖自动备份；校验同源、JSON 结构、`yl.v1.*` 键名与字符串值 |

- 新增 `reading_state` 表，按 `X-Speaking-Scope` 生成 `host:<scope>` 做站内账号隔离；云端不可用时本机继续可练（软失败）。
- 浏览器恢复顺序为「先从数据库恢复 → 再挂载业务 bundle」，避免闪一帧本机旧数据。
- 线上实测：PUT 返回 `{"ok":true}`，GET 回读一致，换账号 GET 返回 `data:null`；换设备后练习记录成功恢复。
- `GET /api/social/challenge` 未加入校园时由 403 改为 200 空数据，消除演示账号的控制台 4xx。

## 六、本轮发现并修复的问题

1. `public/reading/js/views/profile.js` 编辑残留的重复函数声明，且旧 `dist` 未重建 → 学习档案仍显示独立站「本机档案：没有账号」文案。
2. iframe 高度被兜底值锁死（`scrollHeight` 至少等于 iframe 视口高）→ 改为量内容真实底部 + 首帧立即收缩。
3. 空态「单词本」内容 332px 被主站最小高度 420 撑出空白 → 主站下限与模块下限统一 320，四科同口径。
4. 切「学伴互助」卸载 iframe 导致 `net::ERR_ABORTED` 与最后一次进度可能丢失 → iframe 只隐藏不卸载 + `keepalive` 兜底 + 卸载前 flush。
5. 验收脚本用固定 2.4 秒赌首帧，卡在边界偶发误判 → 改为等模块上报 ready；实测主站首屏约 2.2s 是四科共有基线，阅读模块自身 120ms 内就绪。
6. 题库卡片三个按钮颜色不一、横幅统计与模块矛盾、独立站残留文案、演示账号 `/api/social/challenge` 403。
7. 顶栏 96% 不透明导致滚动时内容轻微透出 → 改实色。
