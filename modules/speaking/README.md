# 声场 · 雅思口语模考与陪练

本目录是整站中的口语子模块。当前统一 AI 接入与公网部署以 [整站 README](../../README.md) 和 [WorkBuddy 部署说明](../../docs/WorkBuddy部署说明.md) 为准；下面保留子模块开发与历史预览说明。

**双人口语模考和小组周进度接入包。** 请在本目录双击「启动口语协作预览.cmd」，进入 [本机校园搭子](http://127.0.0.1:4176/#campus)。需要 Node.js 22.13 或更高版本。组队匹配、双方录音互评和队友进度需要运行服务端。前后端路由、数据库迁移以及其他三科如何使用同一份进度见 [总网站接入说明](总网站接入说明.md)。

## 直接运行

如果拿到的是早期单文件演示包，用桌面 Chrome 或 Edge 打开「声场口语模考室.html」。选择「自由对话」，点一个话题，输入一句英语后发送，即可看到反馈和追问。这个入口用于设备上的个人练习。新版总网站接入包使用上方的本机服务启动方式。

如本机浏览器限制文件页录音或存储，在解压出的 `speaking-a` 文件夹内运行下列命令，然后访问 [本机工作台](http://127.0.0.1:8768/)。

```sh
python -m http.server 8768 --bind 127.0.0.1 --directory dist
```

## 两条演示路线

1. **专项对话。** 选预设话题或输入自己的英文话题，通过文字或录音回答。陪练从上一轮表达中选取细节提出追问。支持听题、查看建议、重答和回听两版录音。若浏览器没有可用的英语转写，可填入自己的答句。点「结束」后在「我的对话」回看。
2. **模考与报告。** 点「快速演练」，允许麦克风、朗读检测句、回听并确认，然后按顺序完成日常问答、题卡准备、独白和深入讨论。交卷前可校正转写。交卷后立即看到本场口语报告、逐题反馈及参考句式。点「分析录音」查看有声区间和较长停顿，点「再练这道题」可带入原题、反馈和首答。选「开始模考」使用完整时长。

## 腾讯云发音评测与跟读

在已经部署并配置腾讯云服务的工作台，访客和登录用户都可打开已交卷模考的「逐题复盘」。选择一条有原声的回答，在「腾讯云发音评测」点击「同意发送本段录音并评测」。每题最多发送开头 60 秒。结果含本次评测可用的发音指标与逐词分，逐词详情有助于定位要练的词。整段结果保存在当前浏览器，已保存的结果可直接回看。

选中一个词，先听浏览器示范音，点「录一遍这个词」，读完后停止，也可等待 15 秒自动停止。回听本次跟读后，可单独发送这次录音做单词评测。腾讯返回音素明细时，页面会显示相应结果。浏览器转写继续用于对话与文本反馈，发音诊断使用麦克风原声。腾讯返回的练习分与雅思 Band 分使用不同量表。双击 HTML 或只运行静态文件服务器时，可以体验本机功能；云端评测需要部署后的服务端入口。

## 反馈与估分

- 本机教练使用可复现的英文转写规则，检查举例、理由、连接词、词汇重复及常见语法问题。达到完整度与样本量要求的完整模考会显示文本练习参考分。发音项需要原声证据。有声时长与停顿来自浏览器对录音波形的分析。
- 生成式对话与文本反馈使用服务器端 DeepSeek。发音与流利度显示腾讯 SOE 百分制，和文本参考分分开；没有校准依据，不生成四维雅思总分。DeepSeek 不接收原始录音。
- OpenAI 服务启用后，登录用户可在自由对话中选择将对话文字发给模型。完整模考需满足完整性要求并保留原始作答。点击「分析原声并估分」才会发送每个部分最多 20 秒的原声节选及对应转写，服务评估流利与连贯、词汇、语法和发音。证据不足的项目留空，四项齐全时展示综合参考分。练习记录页展示最近符合条件的完整模考趋势。所有估分仅供练习，未经官方考官校准。

## 账号、数据库与录音

| 入口 | 模考 | 自由对话 |
| --- | --- | --- |
| 单文件、本机服务、线上访客 | 草稿、已交卷回答及录音保存在当前浏览器 | 对话、重答和录音保存在当前浏览器 |
| 线上登录账号 | 草稿在本机，交卷后题目、转写和场次进入 D1，原声进入 R2。同步后可跨设备回听 | 结束后对话文字同步到账号；自由对话的原声与重答录音保留在原浏览器 |

整站按当前浏览器的站内会话隔离记录，报告与本人封卷场次关联保存；同昵称不能直接找回另一设备的身份。旧模考可通过「导出会话与录音」及记录页 JSON 导入迁移。导出文件包含原声和转写。准备便笺仅保存在本机。

## 构建与部署

在 `speaking-a` 目录执行以下命令。构建脚本仅使用 Node.js 标准库（已用 Node.js 24 验证）。

```sh
node scripts/build-worker.mjs
```

产物为 `dist/server/index.js`。项目的 `.openai/hosting.json` 保存 Sites 项目标识与绑定名。在可提供可信登录身份的 Sites 运行时绑定 D1 数据库 `DB` 与 R2 存储桶 `BUCKET`，按顺序应用 `drizzle/0000_speaking_sessions.sql`、`drizzle/0001_speaking_coach.sql`、`drizzle/0002_soe_usage.sql`，再部署 Worker。部署到另一个项目时请使用目标站点自己的项目信息。通过站点管理界面设置主页的访问范围。服务端根据托管平台提供的登录身份选择访客或账号模式。

**配置腾讯云。** 在购买资源包的主账号下，为应用创建启用 API 访问的专用 CAM 子用户。按照新版口语评测的接口级授权规则，在自定义策略中允许 `soenew:SpeakingAssessmentStream`，资源写 `*`，再将策略绑定给该子用户。取主账号「账号信息」中的 APPID 和子用户的 API 密钥对。主账号 UIN 与 APPID 是不同字段。[腾讯云官方授权列表](https://cloud.tencent.com/document/product/1774/127634) · [腾讯云接入说明](https://cloud.tencent.com/document/product/1774/107347)

Windows 用户在解压目录打开 PowerShell，运行以下命令，然后根据提示输入三项。脚本使用当前 Windows 用户的 DPAPI 加密，在 `%LOCALAPPDATA%\声场\tencent-soe.clixml` 保存配置。脚本只完成本机保存。随后请站点维护者通过 Sites 的运行时密钥配置将 `TENCENT_APP_ID`、`TENCENT_SECRET_ID`、`TENCENT_SECRET_KEY` 设为服务端密钥，重新部署以生效。可以公开分享本项目 ZIP，请始终将自己的密钥和配置文件留在私有环境中。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\配置腾讯云评测凭据.ps1"
```

打开站点的 `/api/soe/status` 可查看 `available` 配置状态。端到端验收时，选一条短录音并明确提交，检查是否出现真实评测结果，然后在腾讯云「口语评测（新版）→ 资源包」核对实际用量。演示站按 UTC 日限制请求，全站每天最多提交 60 段作答、240 次单词跟读，每位访问者分别为 8 段和 24 次。腾讯云的英文自由说按每 20 个词折算一个计费单位，余数向上取整，如 62 词折算 4 次。[腾讯云计费概述](https://cloud.tencent.com/document/product/1774/107342)

启用云端模型时，将 `DEEPSEEK_API_KEY` 配置为站点服务端密钥，可选 `DEEPSEEK_BASE_URL` 与 `DEEPSEEK_MODEL`。文字对话与报告在 `server/coaching.mjs`，共享适配在 `../ai/deepseek.mjs`。`/api/health` 检查数据库与存储，登录后 `/api/coach/status` 仅检查模型配置，不代表真实调用已成功。腾讯仍使用独立评测凭据。交付包不含真实密钥，费用取决于实际调用。

如需重新生成可双击的 HTML 与完整 ZIP，在解压的项目目录执行：

```sh
python scripts/package_speaking.py
```

生成的「声场口语模考室.html」和「声场口语完整项目.zip」位于项目的上一级目录。

## 模块与交接

| 文件 | 职责 |
| --- | --- |
| `dist/app.js`、`dist/engine.js`、`dist/audio.js` | 模考页面、题库计时、封卷、设备检测、录音、可选浏览器转写 |
| `dist/practice.js`、`dist/coach-engine.js` | 自由对话、历史、重答及基于转写的反馈 |
| `dist/report.js`、`dist/acoustics.js` | 报告渲染、声学分析、三部分原声节选 |
| `dist/pronunciation.js`、`server/soe-route.mjs`、`server/tencent-soe.mjs` | 逐题录音与跟读评测界面、用量控制、腾讯云鉴权和评测数据适配 |
| `dist/cloud.js`、`server/` | 身份隔离、账号存储、报告与模型服务 |

模考交卷后分发浏览器事件 `speaking-a:submitted`。事件的 `detail.sessionId` 标识场次，`await detail.loadPayload()` 可读取与导出文件一致的 `speaking-a.handoff.v1` 数据，包括逐题原题、转写、时长、音频格式与 base64 原声。其他模块应使用场次标识处理重复交卷。
